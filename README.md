# notes-app
Application web de prise de notes permettant de créer, consulter, modifier et supprimer des notes (taches). Elle facilite l'organisation des taches quotidienne de l'utilisateur(sport,visite d'un lieu, etc...) à faire grâce à une interface intuitive. Ce projet met en pratique le développement full-stack, la gestion des données et la conception d'une application évolutive.
